# Privacy Policy — BC Report Checker

**Last updated:** 29 September 2026

BC Report Checker is a browser extension designed to assist employees with checking and processing store reports in Microsoft Dynamics 365 Business Central.

## Data processed

The extension may process website content from the company Business Central environment that is necessary to provide its report-checking functionality, such as store identifiers, report status information, and report-related page data.

The extension may also store temporary session state locally in the browser so that an active check can continue correctly.

## Data not collected

BC Report Checker does not intentionally collect or store:

- passwords or authentication credentials;
- payment or financial information;
- health information;
- precise location data;
- personal communications;
- browsing history unrelated to the extension's single purpose;
- data for advertising, profiling, lending, or creditworthiness purposes.

## Data transfer

Data required for the extension's functionality may be sent to the BC Report Checker backend service and Cloudflare Worker used to perform report checks and return results.

User data is not sold or transferred to third parties for advertising, marketing, or unrelated purposes.

## Data use

Processed data is used only for the extension's single purpose: checking, displaying, and processing report information in the supported Business Central environment.

## Data retention

Temporary browser session state is kept only as needed for the current workflow. Backend data is retained only as required for the report-checking functionality and operational troubleshooting.

## Security

BC Report Checker uses HTTPS for communication with its backend services.
